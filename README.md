# Logic Puzzle & Scheduler

Project developed for the Logic for Programming (LP) course at Instituto Superior Técnico.

## Overview
A Prolog-based project focused on logic programming and constraint solving. 

## Key Features
- **Schedule Generation:** Algorithm to automatically generate schedules based on complex restrictions and constraints (e.g., movie nights).
- **Data Analysis:** Logic-based algorithms to analyze and query structured data.
- **Wordle Mockup:** Includes a logic-based solver mockup for the game Wordle.

## Technologies
- Prolog
- Logic Programming

## How to run
Load the file into a Prolog interpreter (e.g., SWI-Prolog) and run the provided queries.
